# DrawRace ExternalSecrets Audit

**Date:** 2026-08-10  
**Namespace:** drawrace  
**Cluster:** iad-acb  
**Status:** ❌ **3 ExternalSecrets failing - OpenBao token required**

## Executive Summary

All 3 DrawRace ExternalSecrets are currently failing to sync because the required secrets don't exist in OpenBao. The ExternalSecret operator cannot fetch secrets from OpenBao until they are created. This is a **known blocker** documented in task nd-t2fq.

## Resolution Path

### Automated Setup (Recommended)

```bash
# 1. Obtain OpenBao root token from cluster admin
export OPENBAO_TOKEN="<paste-root-token-here>"

# 2. Run automated setup
cd /home/coding/drawrace
./scripts/setup-openbao-secrets.sh
```

**What the script does:**
1. Creates GarageBucket `drawrace-ghosts` (50Gi quota, versioning enabled)
2. Creates GarageKey `drawrace-api-key` for API S3 access
3. Creates GarageKey `drawrace-postgres-backup-key` for backup S3 access
4. Extracts S3 credentials from Garage-generated secrets
5. Generates secure Postgres credentials
6. Populates OpenBao with all required secrets
7. Verifies ExternalSecrets sync successfully
8. Cleans up temporary secrets
